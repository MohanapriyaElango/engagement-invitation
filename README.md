# 💍 Jayanth & Ranjani - Engagement Invitation

A premium digital engagement invitation with stunning animations, envelope opening, scratch-to-reveal, and more.

## Features
- ✉️ Interactive envelope opening animation
- ✨ Particle effects and floating petals
- 🎆 Scratch-to-reveal engagement details
- ⏰ Live countdown timer
- 🎶 Background music with toggle
- 🎊 Confetti celebration on final page
- 📱 Fully responsive (mobile-first)
- 👆 Swipe/scroll navigation with keyboard support

## 🚀 Steps to Host (FREE) & Share with Everyone

### Option 1: GitHub Pages (Recommended - 100% FREE)

1. **Create a GitHub account** (if you don't have one):
   - Go to https://github.com and sign up

2. **Create a new repository**:
   - Click the "+" icon → "New repository"
   - Name it: `jayanth-ranjani-engagement` (or any name)
   - Make it **Public**
   - Click "Create repository"

3. **Upload files**:
   - Click "uploading an existing file"
   - Drag and drop all 3 files: `index.html`, `styles.css`, `script.js`
   - Click "Commit changes"

4. **Enable GitHub Pages**:
   - Go to repository **Settings** → **Pages** (left sidebar)
   - Under "Source", select **main** branch
   - Click **Save**
   - Wait 1-2 minutes

5. **Your link will be**:
   ```
   https://YOUR-USERNAME.github.io/jayanth-ranjani-engagement/
   ```

6. **Share this link** with everyone via WhatsApp, SMS, etc.!

---

### Option 2: Netlify (FREE - Even Easier)

1. Go to https://www.netlify.com and sign up (use GitHub/Google)
2. Click **"Add new site"** → **"Deploy manually"**
3. Drag and drop the entire `engagement-invitation` folder
4. Done! You'll get a link like: `https://random-name.netlify.app`
5. You can customize the URL in site settings

---

### Option 3: Vercel (FREE)

1. Go to https://vercel.com and sign up
2. Install Vercel CLI: `npm i -g vercel`
3. In terminal, navigate to this folder and run: `vercel`
4. Follow prompts — your site will be live!

---

### Option 4: Firebase Hosting (FREE)

1. Go to https://console.firebase.google.com
2. Create a new project
3. Go to Hosting → Get Started
4. Install: `npm install -g firebase-tools`
5. Run:
   ```bash
   firebase login
   firebase init hosting
   firebase deploy
   ```

## 🎨 Customization

- Edit `index.html` to change names, dates, venue
- Edit `styles.css` to change colors (look for `:root` variables at the top)
- Replace the music URL in the `<audio>` tag with your preferred song
